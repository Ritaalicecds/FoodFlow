# Interface Mobile — FoodFlow

## Situação do projeto

Nesta versão do FoodFlow, não foi desenvolvida uma aplicação mobile funcional.

Foi criado um protótipo visual no Canva para representar a interface planejada para o sistema.

## Fluxo das telas

O fluxo planejado é:

```text
LOGIN
  ↓
INÍCIO
  ↓
CARDÁPIO
  ↓
DETALHES
  ↓
CARRINHO
  ↓
CONFIRMAÇÃO
  ↓
PEDIDO
  ↓
ACOMPANHAMENTO
  ↓
HISTÓRICO
```

## Objetivo do protótipo

O protótipo tem como objetivo demonstrar a organização das telas, o fluxo de navegação e a experiência planejada para o usuário.

## Ferramenta utilizada

Canva

## Observação

O protótipo representa uma proposta visual e não corresponde a uma aplicação mobile executável.
